# E-Commerce Sales Analysis Dashboard

## Project Overview
This project analyzes a 500K+ row e-commerce dataset using SQL, Excel, and Power BI to identify sales trends, customer behavior, and top-performing products.

## Tools Used
- SQL
- Excel
- Power BI

## Key Insights
- Revenue was heavily concentrated in the United Kingdom
- Sales showed strong seasonal growth during later months of the year
- A small group of customers contributed significantly to total revenue
- Top-performing products accounted for a major share of sales volume

## Dashboard Features
- Country-wise Revenue Analysis
- Monthly Sales Trend Analysis
- Customer Spending Analysis
- Product Performance Analysis
